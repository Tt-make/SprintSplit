# SprintSplit

Garmin GPSウォッチ用の、100m/200m/400mなどのスプリント（短距離走）練習向けアプリです。

アプリを開いた瞬間から通常の「ラン」と同じようにアクティビティ記録（GPS・距離・速度・心拍・ケイデンス・消費カロリーなど）が始まり、それとは別に**あらかじめ設定した複数の秒数（例: 13秒, 26秒, 55秒）ごとに音やバイブで知らせてくれる**サブ機能を、ボタン一つで開始できます。最後の秒数に到達すると1本ぶんの計測が自動で終わってスピードカーブが表示され、そのまま次の1本を始められます。スプリットごとの速度は自動で記録され、グラフでも確認できます。

## できること（機能一覧）

- **メイン機能**：アプリ起動と同時に自動でアクティビティ記録を開始（GPS、距離、速度、心拍数、ケイデンス、カロリーなど、その端末で取得できる情報をできるだけ多く記録）
- **サブ機能（スプリット通知）**：ボタン一つで開始。設定した複数の秒数に到達するたびに知らせ、**最後の秒数に到達すると自動で計測を終了**してスピードカーブ画面に切り替わります。SELECTを押せばすぐ次の1本を開始でき、何本でも繰り返せます
- **知らせ方を選べる**：**音のみ（既定）／バイブのみ／音＋バイブ**から選択。設定は保存されます
- **1本ごとの結果を保持**：走った1本ごとの結果が残り、スピードカーブでは**前回の1本が薄い線で重ねて表示**されるので、本数を重ねたときの比較ができます
- **ディレイスタート（任意）**：オンにすると、ボタンを押してから設定した秒数だけ待機し、「GO」の合図をしてからスプリット計測が始まる（陸上のスタート合図のような使い方ができます）
- **スピードカーブ表示**：計測中の速度を**1秒ごとに記録**して折れ線グラフで表示。**計測中に出た最高速度**も点線と数値で重ねて確認できる
- **プリセット3つを保存・切り替え**：スプリット秒数の設定を3セットまで保存でき、時計のMENUから使うセットを選べる（例：100m用／200m用／400m用）
- **時計画面**：現在の時刻・日付・バッテリー残量を1画面まるごと使って表示（記録は裏で続いています）
- **時計単体で設定変更が可能**：スマホがなくても、時計のMENUボタンからプリセットの切り替え、スプリット秒数の追加・編集・削除、ディレイスタートのON/OFF・秒数変更ができる
- **記録したランはGarmin Connectに保存**：通常の「ラン」アクティビティとして保存され、Garmin Connectアプリで確認できる。各スプリットは**ラップ**として記録され、最高速度とスプリット数もアクティビティの情報として書き込まれます

## 対応デバイス

以下のGarmin GPSウォッチに対応しています（Connect IQ対応の他のランニングウォッチでも、ビルド時にデバイスを追加すれば動作する可能性があります）。

| シリーズ | 対応モデル |
|---|---|
| fēnix 7 | fenix7 / fenix7s / fenix7x |
| Forerunner | fr255 / fr255s / fr265 / fr265s / fr965 |
| Venu | venu2 / venu3 / venu3s |
| epix | epix2 |

> 対応デバイスを追加したい場合は、[manifest.xml](manifest.xml) の `<iq:products>` にデバイスIDを追加してビルドし直してください。

## 必要なもの

- 上記いずれかのGarmin GPSウォッチ
- ウォッチとパソコンをつなぐUSBケーブル（充電ケーブルで可）
- **Garmin Connect Mobile**アプリ（記録したランをGarmin Connectに同期するために使います。App Store / Google Playから無料でインストールできます。※サイドロード〈手動インストール〉したアプリのため、スマホ側の「インストール済みアプリ」一覧には表示されません。設定はすべて時計のMENUから行います）
- （自分でビルドする場合のみ）Windows または macOS のパソコン、[Connect IQ SDK](https://developer.garmin.com/connect-iq/sdk/)、`openssl`（macOSには標準で入っています）

## インストール手順（自分でビルドする）

Garmin Connect IQのアプリストアには公開していないため、Connect IQ SDKを使ってソースコードから `.prg` ファイルを自分でビルドし、**「サイドロード」**という方法でウォッチに直接インストールします。難しい作業ではありません。ここでは要点だけを説明します。**全機種分のビルド方法、接続方式の違い、トラブルシューティングは [BUILD.md（ビルド手順書）](BUILD.md) にまとめてあります。**

> `.prg` は**機種ごとに別物**です。fēnix 7 用のファイルは Forerunner 265S では動きません。使う機種を指定してビルドしてください。

#### 1. このリポジトリをダウンロードする

Gitが使える場合：

```bash
git clone <このリポジトリのURL>
cd SprintSplit
```

Gitを使わない場合は、GitHubページ右上の「Code」→「Download ZIP」からダウンロードし、好きな場所に展開（解凍）してください。

#### 2. Connect IQ SDKを用意する

Garmin developerアカウント（[developer.garmin.com](https://developer.garmin.com/)で無料登録可）が必要です。

Garmin公式の [Connect IQ SDK Manager](https://developer.garmin.com/connect-iq/sdk/)（Windows / macOS 対応のGUIアプリ）をインストールし、

1. Garminアカウントでログイン
2. 最新の **SDK** をダウンロード（`Download` → 使うバージョンを `Set as current` にする）
3. **Devices** タブで、使う機種（fenix7 / fr265s など）のデバイスファイルをダウンロード

の3つを行ってください。macOSではSDKが `~/.Garmin/ConnectIQ/Sdks/` に入り、現在使うSDKのパスが `~/.Garmin/ConnectIQ/current-sdk.cfg` に記録されます（下のビルドスクリプトはこのファイルを自動で読みます）。

> ターミナル派の方は、非公式のCLI [connect-iq-sdk-manager-cli](https://github.com/lindell/connect-iq-sdk-manager-cli) でも同じことができます。その場合もビルドスクリプトがSDKのパスを自動検出します。

#### 3. ビルドする

同梱の [build.sh](build.sh) を実行するだけです。**署名鍵（自分専用の暗号鍵）が無ければ自動で作成**し、`bin/` フォルダも自動で用意されます。

```bash
./build.sh fr265s
```

`bin/SprintSplit_fr265s.prg` が生成されます。`fr265s` の部分をお使いの機種のIDに置き換えてください。

**指定できる機種ID**は次の通りです（`./build.sh --list` でも確認できます）。

| シリーズ | 機種ID |
|---|---|
| fēnix 7 | `fenix7` / `fenix7s` / `fenix7x` |
| Forerunner | `fr255` / `fr255s` / `fr265` / `fr265s` / `fr965` |
| Venu | `venu2` / `venu3` / `venu3s` |
| epix | `epix2` |

**対応する全機種をまとめてビルドする**（複数のウォッチを持っている、配布用にすべて用意したいとき）:

```bash
./build.sh --all
```

**シミュレータで動かしたい場合**（ウォッチが無くても動作確認できます）:

```bash
./build.sh fr265s --run
```

**スクリプトを使わず手動でビルドする場合**:

```bash
mkdir -p ~/.garmin-keys && chmod 700 ~/.garmin-keys && (umask 077 && openssl genrsa -out ~/.garmin-keys/developer_key.pem 4096 && openssl pkcs8 -topk8 -inform PEM -outform DER -in ~/.garmin-keys/developer_key.pem -out ~/.garmin-keys/developer_key.der -nocrypt)
```

```bash
SDKROOT=$(cat ~/.Garmin/ConnectIQ/current-sdk.cfg) && "$SDKROOT/bin/monkeyc" -f monkey.jungle -d fr265s -o bin/SprintSplit_fr265s.prg -y ~/.garmin-keys/developer_key.der -r
```

> **署名鍵について**：`developer_key.pem` / `.der` は開発者ごとに固有のもので、他人と共有したりGitHubに公開したりしてはいけません。誤ってコミットされることのないよう、**鍵はリポジトリの外**（既定では `~/.garmin-keys/`）に置きます。別の場所を使いたい場合は `GARMIN_KEY_DIR=/path/to/keys ./build.sh fr265s` のように指定してください。同じ鍵でビルドしたアプリは「同じ開発者のアプリ」として扱われるため、鍵を作り直すと設定が引き継がれない場合があります。
>
> **`bin/` フォルダについて**：ビルド成果物はリポジトリに含めていません（`.gitignore` で除外）。クローン直後に `bin/` が無くても、ビルド時に自動で作成されます。

#### 4. ウォッチへ転送する

1. ウォッチをUSBケーブルでパソコンに接続します
2. パソコンに「GARMIN」という名前のドライブ（外部ストレージ）が表示されます。これを開きます
3. `GARMIN` フォルダの中にある `Apps` フォルダ（機種により `APPS` と大文字表記の場合もあります）を開きます。無い場合は `Apps` という名前で新しく作成してください
4. ビルドした `.prg` ファイルを `Apps` フォルダの**直下**にコピーします（`DATA` や `SETTINGS` などのサブフォルダには入れません）
5. パソコンからウォッチを安全に取り外します（Windowsなら「ハードウェアの安全な取り外し」、Macならデスクトップのドライブアイコンを「取り出す」）
6. ウォッチを一度再起動します（電源ボタン長押しなどで再起動。機種により操作が異なります）
7. ウォッチのアプリ一覧（多くの機種はUPボタンやタッチで「アプリ」または「Watch Apps」の一覧を開けます）に **SprintSplit** が表示されればインストール完了です

> 機種ごとの画面サイズ、SDK Managerでのデバイスファイル取得、MTP接続の機種（Forerunner 265 / Venu 3 など）で「GARMIN」ドライブが出てこない場合の対処、トラブルシューティングは [BUILD.md](BUILD.md) を参照してください。

## 基本の使い方

### ボタンの役割

ウォッチのボタン配置・呼び方は機種によって異なりますが（例：fēnixシリーズは「START/STOP」「UP/MENU」、Forerunnerは「START」「LIGHT」など）、本書では共通の役割名で説明します。

| 役割 | よくあるボタン位置 | できること |
|---|---|---|
| **SELECT / START** | 右上 | スプリット計測の開始／中止、計測完了後に次の1本を開始、メニュー項目の決定 |
| **UP / DOWN** | 左上・左下 | 画面（RUN / SPLITS / SPEED CURVE / TIME）の切り替え、メニュー内のカーソル移動、秒数設定画面での数値の増減 |
| **BACK** | 右下 | 1つ前の画面に戻る／ランの終了メニュー（保存・削除・キャンセル）を開く |
| **MENU**（UPの長押し） | 左上長押し | 設定メニューを開く（プリセットの切り替え、スプリット秒数の編集、知らせ方の変更など） |

### 練習前の準備

- 屋外の、空が開けた場所で使うとGPSの捕捉が速くなります。屋内では距離や速度が正しく計測できません
- 練習内容に合わせて、あらかじめMENUから次を設定しておくと本番がスムーズです
  - **Preset**：使うスプリット秒数のセット（100m用／200m用など）
  - **Split seconds**：選んだプリセットの秒数の中身
  - **Delayed start** / **Delay length**：スタートの合図（カウントダウン）を使うか、使うなら何秒待つか
  - **Alerts**：知らせ方（音のみ／バイブのみ／両方）

### 1. 起動してGPSを捕捉する

1. ウォッチのアプリ一覧から **SprintSplit** を起動します
2. 起動した瞬間から自動でアクティビティ記録が始まり、RUNページが表示されます
3. GPSの電波を受信するまで、環境によって数秒〜数十秒かかります。RUNページの **DIST**（距離）が `0.00` から動き始めれば捕捉できています。心拍数（HR）は手首の光学式センサーが安定するまで少し遅れて表示されます

### 2. スプリットを1本走る

1. スタートの準備ができたら **SELECT** を押します。自動的にSPLITSページへ切り替わります
   - **Delayed start がOFF**の場合：押した瞬間に「GO」の合図が鳴り、即座に計測が始まります
   - **Delayed start がON**の場合：`READY 3` → `READY 2` → `READY 1` とカウントダウンが表示され、0になった瞬間に「GO」の合図（Alertsの設定に従い音・バイブ・両方）が鳴って計測が始まります
2. 合図と同時に走り出します。SPLITSページ中央に、この1本の経過秒数がリアルタイムで大きく表示されます
3. あらかじめ登録した秒数（例：13秒・26秒・55秒）に到達するたびに、通知で知らせてくれます
4. **最後に設定した秒数に到達すると計測が自動的に終了**し、経過秒数は最終タイムで止まります。画面は自動的に**SPEED CURVEページに切り替わり**、この1本の速度の推移と最高速度をすぐに確認できます

### 3. 続けてもう1本走る（何本でも）

- 息が整ったら、そのまま **SELECT** を押すと次の1本がすぐに始まります（Delayed startがONなら、また合図のカウントダウンが入ります）
- SPEED CURVEページでは、直前の1本が薄い線として新しい1本に重なって表示されるので、その場で伸びたか落ちたかを比較できます
- 走った本数の結果は直近12本ぶんアプリ内に保持されます。何本走っても、すべて同じ1つのアクティビティ（ラン）の中に記録されます

### 4. 途中でやめたい・やり直したいとき

- 計測中（RUNNING）に **SELECT** を押すと、その場で計測を中止できます。そこまでの記録は保持されます
- 今回の計測結果だけをやり直したい場合は、MENUの **Reset splits** で結果だけをクリアできます（スプリット秒数などの設定は消えません）

### 5. 練習の合間に他の画面を見る

**UP / DOWN** で RUN → SPLITS → SPEED CURVE → TIME の4画面をいつでも切り替えられます。どのページを表示していても、アクティビティの記録とスプリット計測は裏で継続します。心拍やケイデンスを見たいときはRUN、時刻を確認したいときはTIME、といった使い方ができます。

### 6. 練習を終えて保存する

1. 練習がすべて終わったら **BACK** を押します
2. **END RUN** メニューが開き、3つから選べます

| 項目 | 動作 |
|---|---|
| **Save run** | アクティビティを保存してアプリを終了します（Garmin Connectに同期されます）|
| **Discard run** | 記録を**保存せずに削除**します。取り消せないため「Discard run?」の確認が出ます（初期選択は「いいえ」）|
| **Cancel** | 保存も削除もせず、ランに戻ります。BACKボタンを押しても同じです |

3. ウォッチとスマホ（Garmin Connect Mobile）が同期すると、Garmin Connectのアクティビティ一覧にランとして表示されます（詳しくは[記録したランをGarmin Connectで見る](#記録したランをgarmin-connectで見る)）
4. 記録を残したくない場合は、MENUの **Discard run** からでも同じ削除ができます（こちらも確認画面が出ます）

## 画面と機能の詳しい説明

UP / DOWNボタンで次の4つの画面を順番に切り替えられます。画面下部の点（ドット）が現在の画面位置を示します。

### 1. RUNページ（メイン画面）

アプリ起動時から常に記録されている、ラン全体の情報を表示します。

- 経過時間（大きく中央に表示）
- 距離（DIST km）／現在の速度（SPEED km/h）
- 心拍数（HR bpm）／ケイデンス（CAD spm）
- **最高速度（MAX km/h）**／消費カロリー（KCAL）

`MAX km/h` は、アプリを起動してからその時点までにこのランで記録した**最高速度**です。スプリット計測をしていない状態でも常に更新されるので、流しやウォームアップ中の最高速度もそのまま確認できます。

### 2. SPLITSページ（スプリット通知）

サブ機能の状態を表示します。

- 状態表示：`READY`（待機中）／`READY 3`のようなカウントダウン中（ディレイスタート使用時）／`RUNNING`（計測中）／`DONE`（1本ぶんの全スプリットが完了）
- 今回のスプリットの経過秒数（大きな数字。`DONE`になると**最終タイムで止まります**）
- 次のスプリット秒数までの残り時間
- 到達したスプリットの数を示す進捗バー
- 直前に到達したスプリットの秒数と、そのときの速度
- 見出しの `SPLITS P1` は、使用中のプリセット番号です

**SELECT**の動作：待機中に押すと計測開始、計測中に押すと中止、`DONE`のときに押すと**次の1本を開始**します。設定した最後の秒数に到達すると、押さなくても自動的に計測が終わり、SPEED CURVEページへ切り替わります。

### 3. SPEED CURVEページ（速度グラフ）

計測中の速度を**1秒ごとに記録**し、その1本ぶんの速度の変化を折れ線グラフで表示します。1本ぶんの計測が完了すると、**このページに自動で切り替わります**。

- **明るい折れ線**：いま表示している1本の速度の推移（1秒ごとの記録）。短い計測（14秒以下）では1秒ごとの点も表示されます
- **薄い折れ線**：その1本前の結果（本数を重ねたときの比較用）
- **点線（MAX）**：その計測中に出た**最高速度**。1秒ごとの記録では一瞬のピークを取りこぼすことがあるため、実際の最高速度は別に記録して重ねています
- **縦の細い線**：設定したスプリット秒数の位置（13秒・26秒…がグラフのどこに当たるか）
- 横軸：`0s` から計測した秒数まで／縦軸：その1本の速度範囲（km/h）
- 上部の `REP 3`：何本目の結果を表示しているか
- 画面下部：`9s   MAX 39.6 km/h` のように、計測した秒数と最高速度を表示
- 計測完了後は `SELECT = NEXT REP` と表示され、**SELECTを押すとその場から次の1本を開始**できます（前の結果は残ります）

スプリットにまだ到達していない状態では「NO SPLIT DATA YET」と表示され、そのときも最高速度（MAX SPEED km/h）だけは大きく表示されます。計測を開始していない間は、アプリ起動後のラン全体での最高速度が表示されます。

### 4. TIMEページ（時計）

現在の時刻を1画面まるごと使って表示します。走っている途中でも、時刻を確認するためにアプリを抜ける必要はありません。

- 時刻（時：分。ウォッチの12/24時間設定に従います）と、その下に秒
- 曜日と日付（例：`SAT 08/15`）
- ラン経過時間（RUN）／バッテリー残量（BATT %）

このページを表示している間も、アクティビティの記録とスプリット計測は止まりません。

## 設定（プリセット・スプリット秒数・ディレイスタート）

設定はすべて**時計単体**で行います。サイドロード（手動インストール）したアプリはGarmin Connect Mobileの「インストール済みアプリ」一覧に表示されないため、スマホ側の設定画面は使えません（詳しくは[よくある質問](#よくある質問注意点)）。

**MENU**ボタン（UPの長押し）を押すと以下のメニューが開きます。

- **Preset**：保存してある3つの設定（プリセット1〜3）から、今使うものを選びます。使用中の行には `*` と `IN USE` が付き、各行にはその秒数（例：`13, 26, 55`）が表示されます。選ぶとその場で切り替わり、印がその行に移ります。**開いたときは前回選んだプリセットにカーソルが合った状態**で表示され、選択内容はアプリを終了しても保存されます（初期状態はいちばん上のプリセット1）
- **Split seconds**：**現在選んでいるプリセット**のスプリット秒数の一覧が表示されます。項目を選ぶと数値をその場で編集でき、「Add split」で追加（1プリセットあたり最大12個まで）、「Clear all」で全削除できます
- **Delayed start**：ディレイスタート機能のON/OFFを切り替えます。ONにすると、SELECTを押してから設定した秒数だけ待ち、「GO」の合図があった瞬間からスプリットの計測が始まります（陸上のスタート合図のような感覚で使えます）
- **Delay length**：ディレイスタートの待機秒数（1〜60秒）を設定します
- **Alerts**：知らせ方を **`sound only`（音のみ・既定）／`vibrate only`（バイブのみ）／`sound + vibrate`（両方）** から選びます。使用中の項目には `*` と `IN USE` が付き、選ぶとその場で切り替わります。設定はアプリを終了しても保存されます
- **Reset splits**：今回計測中のスプリット結果だけをリセットします（秒数の設定は消えません）
- **Discard run**：現在のラン記録を保存せずに削除して終了します。確認画面（初期選択は「いいえ」）を経てから実行されます

現在どのプリセットで走っているかは、SPLITSページの見出し（`SPLITS P1` など）でも確認できます。

### 秒数を変更する画面（ピッカー）の操作

`Split seconds` の各項目、`Add split`、`Delay length` を選ぶと、黒背景の秒数設定画面が開きます。

| ボタン | 動作 |
|---|---|
| **UP** | 数値を増やす |
| **DOWN** | 数値を減らす |
| **START（SELECT）** | 決定して保存 |
| **BACK** | 変更せずに戻る |

- 数値は `31 s` のように**単位付き**で表示されます
- UP / DOWN を続けて押すと、1 → 5 → 10 と変化幅が大きくなるので、大きい秒数にもすぐ届きます
- 開いたときは**現在設定されている値**から始まります（前回選んだ値がそのまま表示されます）
- タッチ対応機種では、画面の上半分／下半分をタップしても増減できます

## 記録したランをGarmin Connectで見る

このアプリの記録は、ウォッチ標準の「ラン」アプリと同じ**アクティビティ（FITファイル）**として保存されます。

1. 練習が終わったら **BACK** を押します
2. **END RUN** メニューで **Save run** を選ぶと、アクティビティが保存されます
3. ウォッチがスマホと同期すると、**Garmin Connectアプリの「アクティビティ」一覧にランとして表示されます**（Garmin Connect Webでも同じものが見られます）

アクティビティに含まれる情報：

- ランニングとして記録された時間・距離・ペース・GPSの軌跡（地図）
- 心拍数、ケイデンス、消費カロリー、標高など、その端末で取得できる項目
- **ラップ**：スプリット計測の開始時と、設定した各スプリット秒数に到達したタイミング、1本の終了時に自動的にラップが区切られます。Garmin Connectのラップ一覧で、各区間のタイム・ペース・心拍を後から見返せます
- アプリ独自の項目としてアクティビティに書き込まれる値：
  - **`max_speed`**：セッション全体の最高速度（km/h）
  - **`splits`**：到達したスプリットの総数
  - **`reps`**：完走した本数
  - **`best_rep`**：一番速かった1本のタイム（秒）
  - **`split_speed`**：各ラップ（スプリット）到達時点の速度（km/h）

何本走っても、1本ごとの結果はすべて同じアクティビティの中にラップとして記録されます。走り終えたら忘れずに保存してください。

> 保存せずに削除したい場合は、BACKの **END RUN** メニュー（またはMENU）の **Discard run** を選んでください（記録は削除され、Garmin Connectには残りません）。**Cancel** を選ぶか BACK を押せば、保存も削除もせずランに戻ります。

## 使用例：100m走のスプリット練習

1. トラックのスタートラインに立ち、SprintSplitを起動する
2. しばらく待ってGPSの電波を掴ませる（RUNページで距離が0.00kmから動き始めればOK）
3. 「Delayed start」をONにし、「Delay length」を3秒に設定しておく（あらかじめMENUから設定）
4. スタートの準備ができたらSELECTを押す → 3秒のカウントダウン後、「GO」の合図（既定では音。MENUの「Alerts」でバイブや音＋バイブにも変更できます）
5. 合図と同時に走り出す
6. 事前に「Split seconds」へ13, 26, 55（100m/200m/400mの目安タイム）を登録しておけば、その秒数に到達するたびに知らせてくれる（別のメニュー用の秒数はプリセット2・3に保存しておき、MENUの「Preset」で走る前に切り替えられます）
7. 最後の55秒に到達すると**自動で計測が終わり**、SPEED CURVEページに切り替わる。1秒ごとの速度変化（どこで加速し、どこから落ちたか）と、その本での最高速度（MAX）を確認する
8. 息を整えたら、そのまま **SELECT** を押して2本目を開始（ディレイスタートONなら再びカウントダウンが入ります）。3本目以降も同じ流れです
9. スピードカーブには前の1本が薄い線で重なるので、「本数を重ねて落ちてきたか」がその場で分かります
10. 練習が終わったら、BACKを押して **END RUN** メニューの **Save run** を選び、ラン全体を保存する（記録を残したくないときは **Discard run**）

## よくある質問・注意点

- **画面の文字が英語（ASCII）表記なのはなぜ？**
  ウォッチのシミュレータや欧文言語設定の端末は英語フォントしか読み込まないため、日本語や記号（♥など）が正しく表示できないことがあります。そのため画面表示はすべて英数字にしています。設定画面（アプリ名や説明文）は日本語のままです。
- **心拍数が表示されない**
  手首光学式心拍計や外部の心拍センサーが有効になっていないと取得できません。ウォッチ側の設定で心拍計測がオンになっているかご確認ください。
- **速度や距離が0のまま動かない**
  屋外でGPSの電波を受信できるまで、数秒〜数十秒かかることがあります。屋内では正しく計測できません。
- **Garmin Connect Mobileの「インストール済みアプリ」一覧にSprintSplitが出てこない／設定画面が開けない**
  これは正常な状態です。Garmin Connect Mobileの「アプリ」一覧に表示され、そこから設定を編集できるのは、**Connect IQストア経由でインストールしたアプリだけ**です。このアプリは`.prg`ファイルを直接ウォッチにコピーする**サイドロード（手動インストール）**方式のため、スマホ側からは認識されず、設定画面も表示されません。設定はすべて時計の**MENU**ボタンから行ってください（[設定（プリセット・スプリット秒数・ディレイスタート）](#設定プリセットスプリット秒数ディレイスタート)を参照）。ウォッチ本体にインストールされていること自体は問題なく、記録したランはこれまで通りGarmin Connectに同期されます。
- **対応していない機種で使いたい**
  [manifest.xml](manifest.xml) の `<iq:products>` に機種のデバイスIDを追加し、上の「インストール手順」の手順でビルドし直せば、その機種向けの `.prg` を作成できます。追加方法は [BUILD.md の「対応機種を追加する」](BUILD.md#11-対応機種を追加する)を参照してください。
- **アプリストアには公開していません**
  個人利用・改造を前提としたオープンなプロジェクトのため、Garmin Connect IQストアでの配布は行っていません。上記のサイドロード方式でご利用ください。

## リポジトリの構成（開発者向け）

```
manifest.xml            対応機種・権限・アプリIDの定義
monkey.jungle           ビルド設定
build.sh                ビルド用スクリプト（署名鍵の作成も自動）
BUILD.md                全機種のビルド手順書・トラブルシューティング
resources/
  settings/             スマホ側設定の項目定義とプロパティの初期値
  strings/              設定画面の文言（日本語）
  drawables/            ランチャーアイコン
source/
  SprintSplitApp.mc     アプリの入口。起動と同時に記録を開始する
  ActivityRecorder.mc   FIT記録・ラップ・センサー取得（アクティビティ本体）
  SplitStore.mc         3プリセット・知らせ方・ディレイの保存／読み込み
  SplitTracker.mc       スプリット計測、カウントダウン、通知、1秒ごとの速度記録
  PageView.mc           4ページ共通の土台（200msの更新タイマー、完了時の画面切替）
  PageDelegate.mc       ボタン操作とページ切り替え
  PageChrome.mc         見出し・罫線・ページドットなど共通の描画部品
  RunView.mc            1ページ目：ラン全体の情報
  SplitView.mc          2ページ目：スプリット計測
  SpeedCurveView.mc     3ページ目：速度グラフと最高速度
  ClockView.mc          4ページ目：時刻
  SecondsPicker.mc      秒数設定画面（自前描画）
  Theme.mc              配色（Garminの64色パレットに合わせた値）
```

`bin/`（ビルド成果物）は [.gitignore](.gitignore) で除外しているため、リポジトリには含まれません。署名鍵（`developer_key.pem` / `.der`）はそもそもリポジトリの外（既定 `~/.garmin-keys/`）に置く方式です。

配色を変えたい場合は [Theme.mc](source/Theme.mc) の数値を、対応機種を増やしたい場合は [manifest.xml](manifest.xml) の `<iq:products>` を編集してください。
